# Single & Multiplanetary System Tabs

This mod adds three tabs to map selection:

1. Multiplanetary Systems - systems with more than one planet
2. Multiplanetary Spawns - systems with more than one starting planet
3. Single Planet Systems

Each tab holds Planetary Annihilation's own systems and the systems of any map packs you have enabled. Outside Galactic War, the tabs also hold your saved systems (My Systems).

These options are also presented in Galactic War when using the mod Shared Systems for Galactic War. There, the tabs do not hold My Systems; select My Systems in the Systems list to use them. A tab also leaves out any system that another selected source already supplies, so with Uber selected it leaves Planetary Annihilation's systems to Uber.

Maps are not included with this mod.

## Installation

You should download and install this mod via the Planetary Annihilation: TITANS in-game [Community Mods](https://steamcommunity.com/sharedfiles/filedetails/?id=1417396826).

## How to Use

1. Install the mod
2. Optionally, install and enable map packs to add their systems to the tabs
3. Use the new tabs when selecting a map
